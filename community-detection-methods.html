Setup code

# install.packages(asnipe)
library(asnipe)
library(igraph)

# creating a graph from Shizuka et al.(2014) network of golden-crowned sparrows
assoc = as.matrix(read.csv("https://dshizuka.github.io/networkanalysis/SampleData/Sample_association.csv",
    header = T, row.names = 1))

# transposing the data
gbi = t(assoc)

# adjacency matrix based on 'simple ratio index' (measure for animal network
# analysis)
mat <- get_network(t(assoc), association_index = "SRI")

# igraph object
g.sparrow = graph_from_adjacency_matrix(mat, "undirected", weighted = T)

set.seed(246)
# note weighted edges
plot(g.sparrow, edge.width = E(g.sparrow)$weight, vertex.label = "", main = "Golden-crowned Sparrow Network",
    sub = "Weighted Edges Reflect Shared Group Strength")

Community Detection in Igraph

Community detection in network analysis involves identifying tightly interconnected groups of nodes within a network. These communities emerge as clusters where nodes have strong connections among themselves, forming cohesive units. Uncovering these distinct communities allows us to gain insights into their internal dynamics within the overarching network structure. Algorithms such as Fastgreedy, Edge Betweenness, and Louvain are important in identifying and understanding these communities, enabling us to develop a deeper understanding of network relationships and behaviors. In this analysis, we will apply these algorithms to the Golden-crowned Sparrow network to identify and explore its community structure.

Fast Greedy

Fastgreedy operates as a hierarchical, agglomerative method for community detection. Initially, each vertex stands as its own community, and through iterative merging, communities are combined to maximize modularity. The algorithm halts when further mergers no longer enhance modularity. While efficient, it may merge relatively small communities due to its immediate, “in-the-moment” decision-making.

Edge Betweenness (Girvan-Newman)

The Edge Betweenness algorithm is a hierarchical, divisive method for community detection. It begins with the entire network as a single community and iteratively removes edges with high betweenness centrality to form new components, creating a nested structure. It is a computationally intensive algorithm but can be effective for smaller networks.

Louvain (Multi-level)

Like Fast Greedy, Louvain starts with each vertex in its own community. When moving nodes between communities, it emphasizes local contributions to overall modularity. Once modularity improvement ceases, communities are collapsed into single nodes, and the process continues. Unlike Fastgreedy, Louvain is particularly adept at detecting smaller, distinct communities, making it more robust across all network sizes.

Algorithm Comparison

Conclusion

By applying Fast Greedy, Edge Betweenness, and Louvain algorithms to the Golden-crowned Sparrow network, we could identify distinct community structures within the network and see the differences in community detection methods. Both the Fast Greedy and Louvain algorithms identified four communities, with both having a Modularity score of 0.609, while the Edge Betweenness algorithm identified three communities with a Modularity score of 0.566. For that reason, I would think the optimal number of communities for this network is likely four.

Each algorithm has its strengths and weaknesses, with Fast Greedy being efficient but potentially merging small communities, Edge Betweenness being computationally intensive but effective for smaller networks, and Louvain being robust across all network sizes and adept at detecting smaller, distinct communities. Understanding these community structures can help us gain a deeper understanding of the Golden-crowned Sparrow network.
